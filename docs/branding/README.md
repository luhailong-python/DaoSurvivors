# 一炁当千

正式命名：**一炁当千**。读作“一气当千”（yī qì dāng qiān）；“炁”是道家气息的用字，以“一骑当千”的熟悉音韵，让人联想到一位道友凭不断组合、进化的道法应对群怪。四字简短，三位角色都适用。

宣传短句：**一人成阵，万妖退散。**

美术沿用本项目已经确定的道家Q版高清手绘：玉绿、米白、暖金为主体，少量朱砂红穗。主Logo采用圆润有劲的定制笔形；葫芦与太极形成独立识别符号，底部云气呼应环绕法器。Logo只保留四字主名，小尺寸不塞进宣传文案。

- `logo-primary-v2-1536.png`、`-768.png`、`-384.png`：主Logo的等比缩小版，均为3:1。

- `logo-emblem-512.png`、`-256.png`、`-128.png`：徽记缩小版。
- `designs/branding/yiqi-dangqian-v1/index.html`：明暗底、尺寸与游戏主视觉搭配预览。
- `BRAND.json`：逐文件SHA、尺寸、原生/缩小区别及Unity导入建议。

图形保持等比，不做九宫格，不拉伸字体。四字固定美术字已绘入Logo；宣传短句、版本号和按钮继续使用独立文字层。建议主Logo可见外轮廓四周留至少自身字高的1/4；常规页面优先768版，小于384像素宽的狭窄位置使用葫芦徽记并配普通文字标题。正式品牌现已统一到52屏UI及预览，并纳入完整游戏美术交付包；旧临时名版本留在此前已校验的历史交付ZIP中。

原生图片使用内置image_gen生成/编辑；缩小版本仅做预乘Alpha重采样，没有新增手绘细节。逐图记录在图片旁，提示词与回执在`docs/production/yiqi-dangqian-*`。配置目标和实际返回信息分开记录，工具未披露的后端型号与质量保留null。
