# 道途幸存者 · UI v1

2026-10-26。工作名，道家 Q 版高清手绘。此目录是本轮图片与 UI 的设计交付入口。Unity 源码与排版稿共享素材、配色、功能语义；当前没有 Unity 实机渲染验收。

## 视觉与尺寸

主色玉绿／青绿，内容为象牙米白纸绢，暖金细边，少量桃花、红穗与太极。直接继承已确认邮件与组队成图的手绘材质，完整来源见 `docs/ASSET_SOURCES.json`。生成插画使用内置 image_gen，不使用付费 API。

基准画布 1920×1080。预览在 1280×720 等比缩小；2560×1080 保持居中安全区；竖屏仅用于查看缩略视觉稿，正式 Unity 目标是横屏。人物与图标保持比例，插画 cover 展示不增加原生细节。正文使用随包 Noto Sans SC，中文和状态采用原生文字。

## 控件与状态

主要操作为玉绿金边，次操作为米白金边；角色与关卡选中同时有颜色、边线与文字／勾记。按钮支持焦点、悬停、按下和禁用反馈，动态反馈由 HTML 或 Unity 原生控件产生，不要求另烘焙按钮文字。

角色和关卡选择互不重置。修行成本是设计样例：`40 + 25 × 当前阶数`，最高五阶，伤害每阶 +5%、气血每阶 +10、移速每阶 +3%；不足和满阶均不可购买。实际数值为本地原型合同，未作为线上平衡验收。

升级与暂停冻结历练；升级必须选择后继续。设置返回既有暂停／升级状态。放弃未完成历练须在游戏界面内确认且不领币。结算只领取一次。HTML 用于各状态视觉演示；真正的存档、暂停与单次结算逻辑在 Unity 源码中分别实现，尚待引擎验证。
